# Политика IT-SOFT-004: Установка программного обеспечения

## 1. Принцип
На корпоративные устройства устанавливается только ПО из каталога Software Center либо ПО, согласованное IT Security.

## 2. Разрешено без заявки
- Обновления уже установленного корпоративного ПО.
- Утилиты из Software Center (браузеры, офисный пакет, VPN-клиент, корпоративный мессенджер).

## 3. Требует согласования
Любое стороннее ПО, IDE-плагины с сетевым доступом, облачные синхронизаторы, удалённые админ-инструменты.
Процедура: заявка «Software Exception» → руководитель → IT Security. Срок рассмотрения до 3 рабочих дней.

## 4. Запрещено
- Пиратское / crack-ПО.
- Майнеры, анонимайзеры без исключения Security.
- Отключение антивируса и EDR.

## 5. Ответственность
Нарушение политики фиксируется как security event; повторные нарушения эскалируются руководителю и HR.
