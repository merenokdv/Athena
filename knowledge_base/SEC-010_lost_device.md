# Регламент SEC-010: Утеря / кража корпоративных устройств

## 1. Область действия
Ноутбуки, смартфоны, токены MFA, корпоративные USB-накопители.

## 2. Немедленные действия сотрудника (первые 30 минут)
1. Позвонить в Service Desk / дежурному SOC и сообщить о факте утери/кражи.
2. Если возможно — удалённо заблокировать экран через корпоративный MDM (Self-Service).
3. Не публиковать детали инцидента в публичных чатах.

## 3. Действия IT Security
1. Принудительный wipe / lock устройства через MDM.
2. Отзыв VPN, AD-сессий, OAuth-токенов в течение 1 часа после регистрации.
3. Смена паролей учётных записей пользователя.
4. Фиксация инцидента класса Security Incident (приоритет не ниже P2; при признаках компрометации данных — P1).

## 4. Документы
Сотрудник в течение 2 рабочих дней предоставляет служебную записку; при краже — копию заявления в полицию (если применимо по локальному праву).

## 5. Выдача замены
Временный ноутбук выдаётся после согласования руководителя и IT Asset Manager, обычно в течение 1 рабочего дня.
